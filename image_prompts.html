Teacher tool

Image prompts

How to use: generate or source each image, save it into the images folder using the exact filename shown (.jpg or .png), and it replaces the placeholder automatically. No code changes are needed. Until then, each place just shows a grey placeholder box.

Sizes: hero images show at a wide 21:9 crop, so keep the subject in the middle band (about 1600 x 690). Example images show at 16:10 (about 1280 x 800). Under 400 KB each keeps the page fast on school wifi.

For a consistent look add this to the end of every prompt: editorial documentary photograph, natural light, muted realistic colours, no text, no logos, no watermark. (Already included below.) Check anything generated for biological accuracy before use.
