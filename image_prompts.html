Teacher tool

Image prompts

Easy transfer: drag a finished image onto its box (or click the box to choose a file). It is resized and saved as the correct images/<name>.jpg for you. The preview shows the exact crop students will see.

Save straight into the project (Chrome or Edge): click Connect images folder once, pick the images folder inside biotech_lab, and every image you drop is written there automatically. In other browsers each drop gives you a correctly named download to move into that folder.

Palettes: for images that must match each other (the calves, the bulls), generate one sheet with all of them, drop it in the palette box, line the yellow grid up with the pictures, and click Split and save. Each picture is cropped out and saved under its own filename.

Prompts: each already ends with a style line for a consistent look. Check anything generated for biological accuracy before use.

Not connected: saves will download instead.
