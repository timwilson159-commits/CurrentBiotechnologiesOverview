Drop zone calibration

This sets exactly where the gene has to land for the Station 4 drag-and-drop to count it as correct. Nothing is auto-detected: the game only checks whether the middle of the gene is inside the green box you set here.

  1. Drag the green box so it covers the gap in the plasmid (resize it with the round handle at its bottom-right corner, or type exact numbers).
  2. Drag the green insulin gene around to test it. The message below tells you whether it would count.
  3. Click Download dropzones.js and save it over js/dropzones.js, or copy the text and paste it in.
